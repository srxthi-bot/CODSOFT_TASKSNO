## Task 1 — Data Cleaning & Preprocessing

### Objective

The objective of this task is to import a dataset using Python, inspect its structure, identify missing values and duplicate records, handle data-quality issues, correct data types, and prepare the dataset for further analysis using Pandas.

### Dataset

**Dataset:** Titanic Dataset

The dataset contains information about Titanic passengers, including age, sex, passenger class, fare, embarkation details, and survival information.

### Tools & Technologies

- Python
- Pandas
- NumPy
- Seaborn
- Google Colab
- GitHub

### Data Cleaning Steps

1. Imported the Titanic dataset using Python.
2. Inspected the dataset structure and dimensions.
3. Examined column names and data types.
4. Identified missing values.
5. Checked for duplicate records.
6. Examined categorical values for inconsistencies.
7. Handled missing numerical values using median imputation.
8. Handled missing categorical values using mode imputation.
9. Replaced missing deck information with `Unknown`.
10. Removed duplicate records.
11. Converted appropriate categorical columns to the `category` data type.
12. Verified the cleaned dataset.
13. Exported the cleaned dataset as `cleaned_titanic.csv`.

### Files

| File | Description |
|---|---|
| `TASK_1.ipynb` | Google Colab notebook containing the complete Python analysis and cleaning process |
| `cleaned_titanic.csv` | Cleaned Titanic dataset |

### Conclusion

The Titanic dataset was successfully cleaned and prepared for further analysis using Python and Pandas. Missing values and duplicate records were handled, data types were reviewed and corrected, and the cleaned dataset was exported as a CSV file.
